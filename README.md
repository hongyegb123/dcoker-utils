# dcoker-utils
some useful script for docker

## Supported Distributions
- Ubuntu
- Arch Linux
- SUSE
- Debian
- CentOS

## Usage

### Install Docker
To install Docker on Ubuntu, Arch Linux, SUSE, Debian, and CentOS, run the following command:
```bash
./install_docker.sh
```

### Install Docker Compose
To install Docker Compose on Ubuntu, Arch Linux, SUSE, Debian, and CentOS, run the following command:
```bash
./install_docker-compose.sh
```
